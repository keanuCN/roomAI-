# roomAI 视觉与交互约定

设计先于代码。以 docs/prototypes/ 中三个独立屏幕为参考：工作台、编辑器、客户方案展示。

## 原型观察

- 工作台：固定窄侧栏，顶部细线面包屑；暖白底、左上方大号中文宋体、右侧天然材质拼接；项目图片为主体，第一张略宽；底部浅鼠尾草绿流程条。
- 编辑器：中央大图占主要面积；右侧约 300px 设置区；视图切换、风格图块、缩略图与材料样本层级分明；主按钮橄榄绿。
- 客户页：以企业品牌导航、满幅客厅图、宋体标题、疏朗产品展示和底部预约栏组织页面。

## 实现值

- 页面底色 #F8F8F4；墨色 #272C25；主色 #596549；浅绿底 #EEF0E7；分隔线 #E5E6DF。
- 桌面侧栏 214px；工作台侧边距 40px；编辑器设置区 315px；间距以 8/12/16/24/40px 为节奏。
- 标题使用 Noto Serif SC / 宋体，界面文字为系统无衬线；远程字体失败时使用本机回退字体。
- 主区域圆角 10–12px，表单 6–7px；界面不堆叠大阴影，不采用蓝紫 AI 渐变。
- 家居图保持暖色、原木、亚麻、石材和橄榄绿的一致视觉语言。

## 交互

- 导航区分工作台、项目与产品；表单、操作结果和失败信息均有反馈。
- 演示生成与真实生成显式区分；生成结果仍需进行真实性与空间尺度审查。
- 弹窗支持 Escape、焦点约束与关闭后焦点恢复；家具支持方向键移动和撤销/重做。
- 小屏侧栏折叠为图标，编辑器设置区移至画布下方；客户页单列展示产品。
